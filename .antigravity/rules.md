# Midgard Geo-Tactics Workspace Rules

1. Read `PROJECT_CONTEXT.md` before making architectural or UI changes.
2. Always run `node build.js` after editing any file in `src/` so `dist/app.bundle.js` is updated.
3. Never implement Disgaea "Lift & Throw".
4. Preserve the Matte Anime Pixel-Art style (no neon glow, no stick figures) and the exact 8 equipment slots (`Headgear, Armor, Right Hand, Left Hand, Legs, Shoes, Amulet, Trinket`).
5. Keep the GRIDHUNT modal UI layout (`#charModal`, `#invModal`, `#skillModal`, `#atlasModal`, `#npcModal`), `Cinzel` + `Inter` non-battle UI fonts, and `22x22` 2.5D tactical combat depth intact.
